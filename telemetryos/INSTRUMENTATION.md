- ⚠ qr-not-a-noop (`app/core/telemetry.py`:39): The OTLP endpoint passed to OTLPSpanExporter/OTLPMetricExporter over the proto-http transport must include the signal-specific path (e.g. http://localhost:4318/v1/traces and /v1/metrics), but a bare base endpoint like "http://localhost:4318" is passed via the `endpoint=` kwarg, which the http exporters treat as the full URL and do NOT append the signal path. Exports will POST to the wrong URL and silently fail.
